#  ATM Machine Web Project

##  Description

This is a simple ATM Machine simulation built using **HTML, CSS, and JavaScript**.
It allows users to enter their balance, withdraw amount, and PIN to perform a transaction.

---

##  Features

*  PIN validation (only 4-digit allowed)
*  Withdraw money functionality
*  Checks if amount is multiple of 500
*  Minimum balance requirement (₹1000)
*  Error messages for invalid inputs
*  Successful transaction message with remaining balance

---

##  How It Works

1. User enters:

   * Account Balance
   * Withdraw Amount
   * PIN
2. System checks:

   * PIN is valid or not
   * Withdraw amount is multiple of 500
   * Sufficient balance is available
   * Minimum balance is maintained
3. Displays result:

   * Success message OR
   * Error message
